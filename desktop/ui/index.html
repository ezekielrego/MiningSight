TUNNELSIGHT DESKTOP

Everything in its place

The same online workstation, with local connection tools beside it.

Start in three steps

  1. Sign in with browser. Approve the desktop connection in your normal browser. Existing web sessions stay separate.
  2. Open a phone mirror. Connect over USB, or choose Local network to pair Android 11+ with its pairing address and six-digit code. Then Connect using the separate connection address, select the phone and Open phone mirror.
  3. Choose a window and Start stream. In Workspace, open Live and choose a project for captures and recordings.

Local and cloud

The phone mirror and local preview run on your computer. scrcpy and FFmpeg are included; no Android Studio, PowerShell script or manual streaming URL is needed.

Cloud projects, model viewers, AI providers and the shared live relay still need internet. Laptop internet can use a separate connection from your phone’s DJI Wi-Fi. This app does not repair DJI SDK compatibility or add remote phone control to the website.

If something does not connect

  • No phone: enable USB debugging, unlock the phone, approve the computer, check the cable, then Refresh.
  • Black preview: restore the selected window or choose another. Protected content may not be capturable.
  • Delayed live video: choose 480p, avoid other uploads, and use Go live in the web player.
  • Stream interrupted: the bridge retries automatically. Stop cancels retries.

Install, close and uninstall

The installer adds Start menu and desktop shortcuts. Closing the app stops encoders and mirrors started by TunnelSight. Existing independent scrcpy sessions are left alone.

Uninstall from Windows Settings → Apps → TunnelSight Desktop. Cloud projects stay on the server. To remove this computer’s saved desktop settings and sign-in first, use the button below.
